# Decisions

## Rank evidence, not model confidence

Independent corroboration is auditable. A model saying “I am 94% sure” is not.

## Approval binds to content

An identifier can stay the same while the plan changes. The digest binds approval to what was actually reviewed.

## Approval expires

A decision made under old circumstances should not be replayable forever.

## Replay is refused

One approved irreversible action is not a lifetime subscription to the same action.

> The human approves the plan, not the filename.
